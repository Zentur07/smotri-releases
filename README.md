# Smotri для Windows

Совместный просмотр видео с синхронизацией и чатом.

**[Скачать последнюю версию](https://github.com/Zentur07/smotri-releases/releases/latest)**

Скачайте `Smotri-Setup-…exe` из раздела Assets и установите программу.
Node.js, VS Code и аккаунт GitHub для использования не нужны.

После установки Smotri проверяет обновления и загружает их автоматически.
Готовое обновление устанавливается при обычном закрытии программы, не прерывая просмотр.
Следующий запуск откроет новую версию. При отсутствии интернета продолжает работать текущая версия.

Старый ZIP-архив автоматически не обновляется: для перехода один раз установите версию Setup.
Аккаунт хранится отдельно от файлов программы.

Программа пока не имеет платного сертификата подписи Windows. Windows может показать предупреждение о неизвестном издателе.

Видео остаётся у ведущего на компьютере. Комнаты, сообщения чата и временные копии видео удаляются при завершении сеанса.
Аккаунты, друзья и приглашения используют Firebase. Для подключения друзей через интернет ведущий включает доступ через Pinggy.

В этом репозитории размещаются выпуски приложения и процесс сборки установщика. Исходный проект разрабатывается отдельно.
